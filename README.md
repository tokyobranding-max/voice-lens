# Voice Lens

話すを、見える化する。声・口の動き・視線をブラウザだけで分析するプロトタイプです。

公開ページ：https://tokyobranding-max.github.io/voice-lens/

## できること

- **声の立体ビュー**：口を中心に、奥（小さい輪）から手前（大きい輪）へ輪が広がります。声が大きいほど手前まで届き、無音では輪が出ません。
- **音声波形**：発話・無音・強調・フィラー音の候補を色分けして流します。右端の棒が「今」の音量で、立体ビューと同じ値で動きます。
- **分析スコア**：発声の力強さ、滑舌の明瞭さ、話すスピード、抑揚（メリハリ）。声がないときは 0 になります。
- **口の開き**：顔の 68 点を検出し、口の点と開きの幅を映像に重ねます。
- **視線**：まっすぐ・上向き・下向き・横向き・白目を、左上の十字の円で表示します。
- **文字起こし（確認用）**：話した言葉が認識されているかを確かめるための表示です。点数には使いません。
- **レポートと履歴**：録音を止めると結果が出ます。履歴はそのブラウザの中だけに保存されます。

## 使い方

1. 公開ページを Chrome で開きます。
2. 「録音を開始」を押し、マイクとカメラの使用を許可します。
3. 顔を中央の枠に合わせて話します。最初の約 1 秒の視線が「まっすぐ」の基準になります。
4. 「録音を停止」でレポートが開きます。

収録済みの動画・音声を分析するときは、「デモ表示中」または「設定」から「動画・音声ファイルを読み込む」を選びます。

## 測り方と限界

点数はすべて試作段階の仮の換算式です。「分析」タブに、点数の元になった測定値を出しています。

| 項目 | 元にしているもの | 注意 |
| --- | --- | --- |
| 発声の力強さ | 声量、1〜5kHz と低域の差 | マイクの感度で変わる |
| 滑舌の明瞭さ | 音色が切り替わる鋭さ | 母音ごとの判定ではない |
| 話すスピード | 音の山の数 × 補正係数（既定 1.65） | 補正係数は設定で変えられる |
| 抑揚 | 声の高さの幅（半音）、声量のばらつき | 整音済みの音声では声量の差が出ない |
| 立体ビューの数値 | 声量と帯域ごとの強さ | マイク 1 本では方向は測れないため推定表示 |
| フィラー音 | 高さと音色が変わらない伸ばし音 | 「えー」以外の長い母音も拾う |
| 口の開き | 内側の唇の上下の幅 ÷ 口の横幅 | 横顔やマイクで口元が隠れるとずれる |
| 視線 | 目の中の黒い部分の位置 | メガネの反射、色付きレンズ、暗い場所でずれる |

## プライバシー

- 声の分析、顔の検出、視線の計算は、すべてブラウザの中で行います。映像と音声をこのページからサーバーに送ることはありません。
- 文字起こしだけは、ブラウザの音声認識を使うため、声がその提供元（Chrome では Google）に送られます。画面の ON / OFF で止められます。
- 履歴は、そのブラウザの保存領域にだけ残ります。

## ファイル

- `index.html`：アプリ本体。顔検出のモデル（重み）も中に埋め込んであります。
- `vendor/face-api.js`：顔の特徴点検出ライブラリ [@vladmandic/face-api](https://github.com/vladmandic/face-api) 1.7.15（MIT License）。ライセンスは `vendor/face-api.LICENSE` にあります。
